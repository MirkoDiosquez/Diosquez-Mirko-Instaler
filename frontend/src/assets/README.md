# Recursos visuales

Las imágenes `local-interior.jpg` y `local-frente.jpg` son recortes del mockup original incluido en `Documentacion/instaler.docx` (word/media/image2.png). Se conservan las referencias visuales del proyecto; no se presentan como fotografías verificadas del negocio.

Los productos no tienen imágenes en la API. Las tarjetas muestran un ícono de material neutro para evitar asignarles fotografías incorrectas.

La marca se representa con texto y una figura geométrica CSS. Los íconos SVG se centralizan en `components/Icon.jsx`.
